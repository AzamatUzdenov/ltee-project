# LTEE variant calling

Variant calling on three E. coli samples from the Long-Term Evolution Experiment

Author: Azamat Uzdenov ([ORCID 0009-0007-9124-7349](https://orcid.org/0009-0007-9124-7349))

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
Then, from this folder:

```bash
pixi install          # builds the exact environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` must work on a fresh clone of this repository. A GitHub
Action (`.github/workflows/reproduce.yml`) checks that on every push.

## Data

Raw reads: a subset (175,000 read pairs per sample) of three *E. coli* clones
from the Long-Term Evolution Experiment (population Ara-3, generations 5,000,
15,000 and 50,000), prepared by Data Carpentry:
<https://doi.org/10.6084/m9.figshare.7726454> (file `sub.tar.gz`, CC0).
Reference genome: *E. coli* B str. REL606, GenBank CP000819.1 (NCBI).
Details, sample sheet and checksums are in `metadata/`.

## Data availability

The original runs are available under NCBI BioProject PRJNA295606:
SRR2589044, SRR2584863 and SRR2584866. The trimmed and subsampled reads used
here are available from Data Carpentry on figshare
(<https://doi.org/10.6084/m9.figshare.7726454>, CC0).
The reference assembly is GCA_000017985.1 (REL606, CP000819.1), from NCBI.
Provider MD5 values and course SHA-256 values are recorded in `metadata/`.
Run `python scripts/download_data.py` to download and verify the raw files;
use `--verify-only` to check files already present.
Raw data is read-only and excluded from Git. Analysis results have not yet
been generated; later lessons will add the commands to regenerate them.
