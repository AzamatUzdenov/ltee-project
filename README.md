# LTEE variant calling

Variant calling on three E. coli samples from the Long-Term Evolution Experiment

Author: Azamat Uzdenov ([ORCID 0009-0007-9124-7349](https://orcid.org/0009-0007-9124-7349))

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
Then, from this folder:

```bash
pixi install --locked # builds the environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` must work on a fresh clone of this repository. A GitHub
Action (`.github/workflows/reproduce.yml`) checks that on every push.

The analysis runs on Linux and macOS in the `pipeline` environment. The
default environment also supports Windows; use WSL2 for the full analysis
on Windows.

## What is where

| Folder | What goes in it | Rule |
|--------|-----------------|------|
| `data/raw/` | Data exactly as you received it | Read-only. Never edit; download it with a script. Not committed. |
| `data/processed/` | Data derived from raw data | Regenerated by code. Not committed. |
| `metadata/` | Sample sheet, data sources, checksums, data dictionary | Small text files, committed. |
| `scripts/` | Code you write (Python, shell) | Committed. |
| `config/` | Parameters for the analysis or workflow | Committed. |
| `workflow/` | Snakemake and Nextflow pipelines | Committed. |
| `notebooks/` | Jupyter notebooks for exploration | Committed, outputs cleared or small. |
| `reports/` | Quarto documents that turn results into a report | Source committed, rendered HTML not. |
| `results/` | Figures, tables, logs made by the code | Regenerated. Not committed. |
| `docs/` | Longer documentation | Committed. |
| `envs/` | Conda `environment.yml` exports, for people without Pixi | Generated from `pixi.toml`. |
| `containers/` | Dockerfile and Apptainer recipe | Committed. |

Each folder has its own `README.md` with more detail.

## Data

Raw reads: a subset (175,000 read pairs per sample) of three *E. coli* clones
from the Long-Term Evolution Experiment (population Ara-3, generations 5,000,
15,000 and 50,000), prepared by Data Carpentry:
<https://doi.org/10.6084/m9.figshare.7726454> (file `sub.tar.gz`, CC0).
Reference genome: *E. coli* B str. REL606, GenBank CP000819.1 (NCBI).
Details, sample sheet and checksums are in `metadata/`.

## Data availability

The original runs are available under NCBI BioProject PRJNA295606:
SRR2589044, SRR2584863 and SRR2584866. The trimmed and subsampled reads used
here are available from Data Carpentry on figshare
(<https://doi.org/10.6084/m9.figshare.7726454>, CC0).
The reference assembly is GCA_000017985.1 (REL606, CP000819.1), from NCBI.
Provider MD5 values and course SHA-256 values are recorded in `metadata/`.
Run `python scripts/download_data.py` to download and verify the raw files;
use `--verify-only` to check files already present.
Raw data is read-only and excluded from Git. `pixi run reproduce` verifies
the data, runs FastQC and MultiQC, and rebuilds alignments, variant calls
and summary statistics under `results/`.

## Current progress

This repository is being built step by step for The Art of Reproducible
and Open Science (Aziz Khan), Fall 2026. Lesson 05 replaces the placeholder
with data verification, quality control and variant calling. The default
minimum read depth is 2; the script accepts a depth and an output folder:

```bash
pixi run -e pipeline bash scripts/run_variant_calling.sh 10 results-depth10
```

The MultiQC report is `results/qc/multiqc/multiqc_report.html`; filtered
variant calls are in `results/vcf/`. The Quarto report comes in a later lesson.
