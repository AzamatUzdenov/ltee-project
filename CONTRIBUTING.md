# Contributing

1. Open an issue before a larger change.
2. Create a branch, make the change and run `pixi run reproduce`.
3. Open a pull request; Reproduce must pass before merging.

Keep raw data out of Git, commit `pixi.toml` and `pixi.lock` together,
and record analysis decisions in `docs/decisions.md`.
See [the code of conduct](CODE_OF_CONDUCT.md).
